# Zomato Product Analytics Platform — Project Bible

## Project Overview

An **End-to-End Product Analytics Platform** that analyzes a simulated Zomato food delivery ecosystem using SQL, Python, Power BI, and Product Analytics methodologies.

The project identifies business problems, uncovers actionable insights, and recommends data-driven product improvements to enhance customer experience and business performance.

---

## Business Problem

Food delivery platforms handle millions of orders every day. Even a small increase in order cancellations, delayed deliveries, or customer churn can significantly impact revenue and user satisfaction.

This project analyzes a simulated Zomato food delivery ecosystem to identify the key factors affecting business performance. Using data analytics and product thinking, the project uncovers actionable insights and recommends product improvements that enhance customer experience, operational efficiency, and long-term business growth.

---

## Project Objectives

- Analyze customer ordering behavior and identify usage patterns
- Measure key business metrics: Revenue, Orders, AOV, Customer Retention, Cancellation Rate
- Identify root causes of order cancellations and delayed deliveries
- Evaluate restaurant and delivery partner performance
- Generate actionable business insights using SQL and Python
- Design a multi-page Power BI dashboard for executive reporting
- Recommend data-driven product improvements supported by business insights and success metrics

## How to Run — End-to-End

### 1. Install Dependencies
```bash
pip install pandas numpy faker matplotlib seaborn pyodbc
```

### 2. Generate Synthetic Data
```bash
python python/data_generation.py
```
**Output**: 6 CSV files in `data/raw/`

### 3. Set Up SQL Database
1. Open SSMS and connect to your SQL Server instance
2. Run `sql/schema.sql` to create all tables

### 4. Import Data to SQL Server
```bash
python python/import_to_sql.py
```
> Edit the `SERVER` constant in `import_to_sql.py` before running

### 5. Run Analytical EDA
```bash
python python/eda.py
```
**Output**: 15 PNG charts in `data/processed/`

### 6. Run SQL Queries
Open `sql/queries.sql` in SSMS and run queries individually or all at once.

### 7. Build Power BI Dashboard
Follow `dashboard/PowerBI_Setup_Guide.md` step by step.

## Key Business Insights

1. **Cancellation Rate** ~10% — highest in certain cuisines and cities → Opportunity to improve restaurant SLA enforcement
2. **SLA Breach** — significant portion of deliveries exceed 30 minutes → Need for smarter partner dispatch algorithms
3. **Gold Members** have higher AOV → Invest in expanding the Gold membership program
4. **UPI dominates** payment — Cash on Delivery has highest failure rate → Promote digital payments with incentives
5. **Weekend evenings** are peak hours → Ensure higher delivery partner availability during these windows
6. **Customer Loyalty** — A significant portion of customers place only 1–2 orders → Focus on retention campaigns

## Product Recommendations

| Problem | Recommendation | Success Metric |
|---------|---------------|----------------|
| High cancellation rate | Predictive cancellation alert system | Reduce cancellation rate by 20% |
| SLA breaches | Dynamic routing + more partners in peak hours | Improve on-time rate to >85% |
| Low review conversion | Post-delivery nudge notification | Increase review rate to >90% |
| Payment failures | Smart payment retry with UPI fallback | Reduce failure rate by 30% |
| One-time buyers | Personalized re-engagement campaigns | Improve Month-1 retention by 15% |
| Gold member underuse | Enhanced Gold benefits + onboarding | Increase Gold penetration to 40% |
