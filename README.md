## 📌 Project Overview

This project builds a **complete data analytics pipeline** for a simulated Zomato food delivery ecosystem. It covers everything from synthetic data generation to SQL analysis to Power BI dashboards, demonstrating real-world product analytics skills.

**Business Problem**: Food delivery platforms handle millions of orders daily. Even small increases in cancellations, delayed deliveries, or customer churn can significantly impact revenue and satisfaction. This project identifies key factors affecting business performance and recommends data-driven product improvements.

---

## 🎯 Project Objectives

- Analyze customer ordering behavior and identify usage patterns
- Measure key business metrics: Revenue, Orders, AOV, Customer Retention, Cancellation Rate
- Identify root causes of order cancellations and delivery delays
- Evaluate restaurant and delivery partner performance
- Generate actionable insights using SQL and Python
- Design a multi-page Power BI dashboard for executive reporting

## 🚀 How to Run

### Prerequisites
```bash
pip install pandas numpy faker matplotlib seaborn pyodbc
```

### Step 1 — Generate Data
```bash
python python/data_generation.py
```
Outputs 6 CSV files to `data/raw/`

### Step 2 — Create SQL Schema
Run `sql/schema.sql` in SQL Server Management Studio (SSMS)

### Step 3 — Import Data to SQL
```bash
python python/import_to_sql.py
```
> Edit `SERVER` and `DATABASE` in `import_to_sql.py` before running

### Step 4 — Run EDA
```bash
python python/eda.py
```
Outputs 15 PNG charts to `data/processed/`

### Step 5 — Run SQL Queries
Run `sql/queries.sql` in SSMS for all 25 analytical queries

### Step 6 — Power BI Dashboard
Follow instructions in `dashboard/PowerBI_Setup_Guide.md`

## 🔑 Key Insights (Sample)

- **80%** of orders are delivered successfully
- **10% cancellation rate** — highest in certain cuisines and cities
- **SLA breach (>30 min delivery)** affects a significant portion of orders
- **Zomato Gold members** have higher AOV than regular members
- **UPI** is the most popular payment method
- **Weekend evenings** show peak order volume across all cities
